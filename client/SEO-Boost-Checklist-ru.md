# План по улучшению SEO для проекта **client**

## Общий фокус
1. **Структурированные данные** – добавить схемы Breadcrumb, FAQ, Review.  
2. **Мета‑теги и Open‑Graph** – заполнить недостающие теги (author, twitter, размеры изображения).

4. **Производительность** – предзагружать критические ресурсы, сжать изображения, включить HTTP/2 / 3.  
5. **Индексация** – уточнить `robots.txt`, проверить карту сайта, добавить `hreflang` при необходимости.

### 5️⃣ Индексация и сканирование
- **robots.txt** – Добавить комментарий и, при необходимости, запретить служебные пути, например `Disallow: /admin`. 
- **sitemap.xml** – Убедиться, что в карте присутствуют все публичные страницы; при изменениях генерировать её заново (`npm run build && npm exec sitemap-generator-cli`). 
- **hreflang** – При наличии английской версии (`/en/`) добавить `<link rel="alternate" hreflang="en" href="https://day-night-bar.ru/en/">`. 
- **Проверка Rich Results** – Использовать Google Rich Results Test вручную (внешний сервис, сеть недоступна, поэтому делайте проверку в браузере).

## Как работать дальше
1. **Выберите приоритетные задачи** – начните с быстрых правок (метатеги, `alt`‑тексты). 
2. **Редактируйте исходные файлы** (или шаблоны Vite) и после каждой правки запускать `npm run build && npm run check:seo`, чтобы скрипт оставался зелёным. 
3. **Запустите Lighthouse** и исправьте критические проблемы производительности. 
4. **Обновляйте чек‑лист** – отмечайте выполненные пункты галочкой `✔️` в этом файле, чтобы иметь актуальный статус.

Если хотите, чтобы я сразу внес конкретные изменения (добавил JSON‑LD, поправил метатеги, сжать изображения и т.п.), дайте знать, и я выполню нужные команды/правки.
