# План по улучшению SEO для проекта **client**

## Общий фокус
1. **Структурированные данные** – добавить схемы Breadcrumb, FAQ, Review.  
2. **Мета‑теги и Open‑Graph** – заполнить недостающие теги (author, twitter, размеры изображения).  
3. **Контент и доступность** – добавить `alt`‑тексты, соблюдать логическую иерархию заголовков, добавить атрибуты ARIA.  
4. **Производительность** – предзагружать критические ресурсы, сжать изображения, включить HTTP/2 / 3.  
5. **Индексация** – уточнить `robots.txt`, проверить карту сайта, добавить `hreflang` при необходимости.


### 2️⃣ Метатеги и Open‑Graph (Выполнено ✔️)
| Тег | Рекомендация | Статус |
|-----|--------------|--------|
| `meta name="author"` | Указать название заведения («Бар «День / Ночь»»). | ✔️ Готово |
| `meta name="keywords"` | Добавить целевые ключевые слова (Берёзовский, бар, коктейли, меню, ресторан). | ✔️ Готово |
| `meta property="og:image:width"` и `height` | Указать реальные размеры изображения (2333x3500) + `image:type` и `secure_url`. | ✔️ Готово |
| `meta name="twitter:*"` | Добавлены карточки `summary_large_image`, `twitter:site`, `twitter:creator`, `twitter:title`, `desc`, `image`. | ✔️ Готово |
| `meta name="theme-color"` | Добавлен цвет `#121212` под стилистику бара для мобильных браузеров. | ✔️ Готово |
| `preconnect / dns-prefetch` | Добавлены подсказки для CDN внешних ресурсов (cdnjs FontAwesome). | ✔️ Готово |

**Пример добавлений в `<head>`:**
```html
<meta name="author" content="Бар «День / Ночь»">
<meta name="keywords" content="бар, Берёзовский, коктейли, вечеринки, ночной бар">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:site" content="@daynight_bar">
<meta name="twitter:creator" content="@walentina">
<link rel="preload" href="/assets/index-Dl8tmpJm.js" as="script">
<link rel="preload" href="/assets/index-BF0O9smu.css" as="style">
```
