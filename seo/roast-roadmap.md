## Проверка после деплоя

```bash
curl -I https://day-night-bar.ru/
curl -i https://day-night-bar.ru/robots.txt
curl -i https://day-night-bar.ru/sitemap.xml
curl -i https://day-night-bar.ru/llms.txt
curl -I https://day-night-bar.ru/no-such-page
```

Главная и служебные файлы должны вернуть HTTP 200, а несуществующий адрес — HTTP 404.

## Fluff — не приоритет до задач выше

- Дублируется название «Космополитен» в подписях слайдера.
- При появлении официального расписания добавьте его одновременно в видимый контент и JSON-LD; не указывайте часы работы наугад.
