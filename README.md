# «День / Ночь» — Элитный бар

Полнофункциональный веб-сайт бара с современным дизайном и административной панелью. Проект объединяет минималистичный фронтенд на чистом JavaScript с мощным бэкенд-сервисом на C# для управления контентом в реальном времени.

-----

## Предназначение

Сайт разработан как визитная карточка заведения. Основные цели проекта:

  * **Визуальная презентация:** Демонстрация атмосферы бара и авторских коктейлей через анимированные элементы.
  * **Информирование:** Удобный просмотр актуального меню и действующих акций.
  * **Управление:** Оперативное обновление объявлений и позиций меню через встроенную админ-панель.

-----

## Технологический стек

### Frontend

  * **HTML5**
  * **CSS3** 
  * **JavaScript (ES6+)** 
  * **Система сборки Vite**

### Backend

 * **.NET Framework 10.0**
 * **ASP.NET Core 9.0**
 * **Entity Framework Core 9.0**
 * **PostgreSQL**

### Дополнительно
- **CORS**: Настроена кроссдоменная поддержка между клиентом и сервером
- **Rate Limiting**: Защита от перебора паролей (5 попыток в минуту)
- **Exception Handling**: Централизованная обработка ошибок через middleware
- **IP Banning**: Middleware для блокировки подозрительных IP-адресов
- **Logging**: Полное логирование всех входящих и исходящих запросов

-----

## Архитектура проекта

**Frontend:**
- **Component-Based Architecture**: Каждый элемент UI — это отдельный компонент с независимой логикой
- **Module Pattern**: Разделение функциональности на модули
- **Event-Driven**: Обработка событий пользователя через делегирование

**Backend:**
- **Onion Architecture**: Слоистая архитектура с четким разделением ответственности
- **Dependency Injection**: Использование встроенного DI контейнера ASP.NET Core
- **Middleware Pipeline**: Обработка запросов через middleware

## Установка и запуск

### Требования

- **Node.js** ≥ 22.0
- **.NET SDK** 10.0
- **PostgreSQL** 16+
- **npm**

### Frontend

```bash
cd client
npm i
npm run dev
```

### Backend

```bash
cd server
dotnet restore
dotnet ef migrations add Init
dotnet ef database update
dotnet run
```
